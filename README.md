# 🇷🇺ru-split-amneziavpn
Список всех российских адресов для раздельного туннелирования в AmneziaVPN.

<img width="2816" height="1536" alt="banner" src="https://github.com/user-attachments/assets/5c11713e-a87b-4d9c-8b5f-0df25a13a482" />

Идея проекта простая: все российские адреса должны открываться напрямую, а не через VPN. Они вынесены в отдельный JSON-файл для импорта в AmneziaVPN клиент.

## ❓ Для чего нужен проект

Некоторые российские сайты и сервисы работают нестабильно или ограниченно при подключении через зарубежный VPN.  
Этот репозиторий собирает и поддерживает список всех российских адресов для исключения из VPN-туннеля.

## ℹ Формат файла

Файл совместим с простым форматом:

```json
[
  {
    "hostname": "gosuslugi.ru",
    "ip": ""
  },
  {
    "hostname": "nalog.gov.ru",
    "ip": ""
  }
]
```

# Как использовать

1. Скачайте файл `ru-sites.json`.
2. Импортируйте его в список исключений или split tunneling в AmneziaVPN.
3. Проверьте нужные вам сервисы без VPN-туннеля.

## Отказ от гарантий

Проект поддерживается сообществом и не гарантирует, что каждый адрес будет работать одинаково у всех пользователей.  
Политики доступа, CDN, антибот-защита и геоограничения могут меняться без предупреждения.
